# Design Assets

앱과 웹사이트 제작에 사용한 원본 디자인 에셋을 보관한다. 이 디렉터리는 배포 산출물에 포함되지 않으며, 실제 앱과 웹사이트는 각 배포 경로에 있는 최적화된 파일을 사용한다.

## App Store Screenshots

- `app-store/screenshots/01.png`부터 `06.png`: 1284 x 2778 App Store 스크린샷 원본
- 웹사이트용 변환본: `CommunityAPI/assets/screenshot-*-full.webp`, `CommunityAPI/assets/screenshot-*.webp`

## Brand

- `brand/logo.png`: 전체 앱 아이콘 원본
- `brand/logo-simple.png`: 헤더 등 작은 크기에 사용하는 단순 로고 원본
- 웹사이트용 변환본: `CommunityAPI/assets/bzogak-header-logo.webp`, `CommunityAPI/assets/bzogak-icon.*`

App Store용 확인 이미지는 `docs/AppStore/BZOGAK-AppIcon-1024.png`, 실제 앱 아이콘 원본은 `Overline/BZOGAK.icon`에서 관리한다.
