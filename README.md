## Summary-en

Have you ever wanted to underline a sentence or jot down a thought while reading, but hesitated because you wanted to leave the book unmarked?

BZOGAK is a mobile app for capturing passages you love, keeping reading records, and getting more out of your reading with AI.

When your eyes feel tired, or you want to hear a little more of the story before falling asleep, try AI narration. Photograph the pages you are reading and enjoy your paper book like a personal audiobook.

You no longer have to wonder where you wrote down that favorite passage. Find it with a quick search, then explore your saved passages with AI to discover insights of your own.

### Key Features

- **Underline and save:** Draw a line with your finger over the sentences you want to keep on a captured page, and save them as text. There is no need to copy them out or mark the book itself.
- **Listen to captured pages:** Photograph one or several pages and listen to them continuously with on-device narration, even while the screen is locked or you are using another app.
- **Bookshelf and search:** Organize passages and notes by book, then search titles, tags, and notes to find the records you need.
- **Reading records:** Keep track of reading dates, progress, ratings, and reflections for each book.
- **AI reading notes and insights:** Use saved passages to draft a book reflection, ask questions about a book, summarize its content, and organize your thoughts.
- **Community and book information:** Browse popular books and blog posts about what you are reading, or find nearby bookshops and libraries.

책을 읽다가 눈이 피로할 때, 잠들기 전 읽던 이야기를 조금만 더 듣고 싶을 때는 AI 나레이션을 활용해보세요. 읽던 페이지를 촬영하면 종이책도 나만의 오디오북처럼 즐길 수 있습니다.

마음에 드는 구절을 메모해두고도 어디에 적었는지 찾지 못했던 번거로움도 줄어듭니다. 원하는 문장을 검색으로 다시 꺼내보고, 모아둔 글조각을 AI와 함께 살펴보며 나만의 인사이트를 발견해보세요.

### 주요 기능

- **밑줄긋기:** 촬영한 책 페이지에서 원하는 문장에 손가락으로 밑줄을 그어 텍스트로 저장합니다. 문장을 일일이 옮겨 적거나 책에 직접 표시할 필요가 없습니다.
- **페이지 읽어주기:** 한 장 또는 여러 장을 촬영해 기기 내 음성으로 연속해서 듣습니다. 화면을 잠그거나 다른 앱을 사용하는 동안에도 재생을 이어갈 수 있습니다.
- **책장과 검색:** 글조각과 메모를 책별로 모으고, 제목·태그·메모로 검색해 필요한 기록을 찾습니다.
- **독서 기록:** 책마다 읽은 날짜와 진행 상태, 별점과 감상을 함께 기록해 독서 이력을 관리합니다.
- **AI 독서 메모와 인사이트:** 모아둔 글조각으로 독서 감상문 초안을 만들고, 책에 관해 질문하거나 내용을 요약하며 생각을 정리합니다.
- **커뮤니티와 책 정보:** 인기 도서와 읽고 있는 책에 대한 블로그 글을 살펴보고, 가까운 서점과 도서관을 찾아봅니다.

## Summary-ja

紙の本を読んでいて、線を引いたりメモを書き込んだりしたくても、本はきれいなままにしておきたい。そんな理由でためらったことはありませんか？

BZOGAKは、読書中に気に入った一文を撮影して保存し、読書の記録をまとめながら、AIとともに読書の楽しみを広げるモバイルアプリです。

読んでいるうちに目が疲れたときや、眠る前に物語の続きをもう少しだけ聞きたいときには、AIナレーションを。読んでいるページを撮影すれば、紙の本も自分だけのオーディオブックのように楽しめます。

気に入った一節をメモしたのに、どこに書いたか思い出せない。そんなときも検索ですぐに取り出せます。集めた一節をAIと一緒に読み返しながら、自分ならではの気づきを見つけてみませんか。

### 主な機能

- **線を引いて保存:** 撮影したページの残したい文に指で線を引き、テキストとして保存できます。書き写したり、本に直接印をつけたりする必要はありません。
- **ページの読み上げ:** 1ページでも複数ページでも、撮影した内容を端末内の音声で続けて再生。画面をロックしたり、別のアプリを使ったりしている間も聞き続けられます。
- **本棚と検索:** 保存した一節やメモを本ごとに整理し、タイトル・タグ・メモから必要な記録を探せます。
- **読書記録:** 読んだ日付や進捗、評価、感想を本ごとにまとめて、読書の履歴を管理できます。
- **AI読書メモとインサイト:** 集めた一節をもとに感想文の下書きを作り、本について質問したり、内容を要約したりしながら考えを整理できます。
- **コミュニティと本の情報:** 人気の本や読んでいる本に関するブログ記事を調べたり、近くの書店や図書館を探したりできます。

## Installation

### iPhone App

Use Xcode 26.6, the toolchain used to verify this project, and a physical iPhone running iOS 17.0 or later for camera and audio testing.

```sh
git clone https://github.com/hsu3046/OverlineAI.git
cd OverlineAI
open Overline.xcodeproj
```

1. Select the `Overline` scheme. The built app is named `BZOGAK`.
2. Configure your own signing team and a bundle identifier available to that team.
3. Select your iPhone and build and run the app. Allow camera or microphone access when using the corresponding features.

The project and source directory retain the internal name `Overline`. The public product name is BZOGAK / 글조각 서랍.

### Optional Services

- **External AI:** Configure a provider and your own API key in the app, then consent to sending selected content. Provider charges may apply independently of the free app.
- **High-quality local narration:** Download the optional Supertonic voice model from the app before first use. Once downloaded, narration runs on the device without an internet connection.
- **Community API:** Follow the [backend setup guide](CommunityAPI/README.md) to deploy your own service. Provider credentials belong in server environment variables, not in the iPhone app. Use [the configuration example](Config/Secrets.example.xcconfig) to override the app's API base URL locally.

### Verification

Run the focused library-backup and legacy credential cleanup tests from the repository root:

```sh
bash Tests/LibraryBackupCodec/run.sh
bash Tests/LegacyCredentialCleanup/run.sh
```

After installing the backend dependencies as described in its setup guide:

```sh
cd CommunityAPI
npm run typecheck
npm test
```

Camera capture, speech generation, interruptions, and background playback should also be tested on a physical iPhone.
