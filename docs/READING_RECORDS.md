# 독서 기록

## 개요

책마다 여러 번의 독서 기록을 남길 수 있다. 책 상세 화면에서 가장 최근 기록을 바로 확인하고, 재독할 때는 기존 기록을 덮어쓰지 않고 새 기록을 추가한다.

## 기록 항목

- 독서 상태: 읽는 중, 완독, 잠시 멈춤, 중단
- 독서 날짜: 시작일과 선택적인 종료일
- 별점: 별 위를 탭하거나 쓸어 0.5점 단위로 선택하며, 미평가로 되돌릴 수 있음
- 감상문: 최대 3,000자

완독 또는 중단을 선택하면 종료일을 오늘로 제안한다. 사용자가 선택한 종료일이 시작일보다 빠르면 저장할 때 시작일로 보정한다.

## 화면 흐름

독서 기록 영역은 책 소개 아래, 글조각 검색창 위에 표시한다. 기록이 없으면 첫 기록 추가 동작을, 기록이 있으면 가장 최근 기록의 상태·날짜·별점·감상문 일부를 표시한다. 기록이 두 개 이상이면 전체 기록 목록을 열 수 있다.

기록 편집 화면에서 날짜, 상태, 별점과 감상문을 수정한다. 기존 기록 삭제는 확인 절차를 거친다.

## AI 감상문 초안

책에 저장된 글조각이 있을 때 감상문 옆에 AI 초안 버튼을 표시한다. 현재 설정에서 선택한 AI 제공자와 모델을 사용하며, 책 정보와 해당 책의 글조각·메모를 전송한다.

- 최대 24개 글조각과 약 12,000자 범위에서 독서 흐름 전체를 고르게 참고한다.
- 600-1,000자의 감상문 본문을 요청한다.
- 긴 원문 인용, 사용자가 말하지 않은 경험·감정·완독 여부의 생성을 금지한다.
- 결과는 바로 저장하지 않고 검토 화면에 표시한다.
- 생성 중 감상문, 독서 상태 또는 글조각이 바뀌면 오래된 결과를 적용하지 않는다.
- 글조각 자체를 설명하는 상투적인 표현으로 시작하지 않고 책에서 남은 생각으로 바로 시작한다.

## 책 공유

책 공유에는 책 정보와 글조각에 더해 모든 독서 기록의 독서 날짜, 별점과 감상문을 포함한다. 독서 상태는 공유하지 않는다.

## 저장 호환성

독서 기록은 `ReadingBook.readingRecords`에 포함되어 기존 보관함 스냅샷과 함께 로컬 저장된다. 이전 버전 데이터에 필드가 없으면 빈 배열로 디코딩하므로 기존 책과 글조각을 그대로 유지한다.
