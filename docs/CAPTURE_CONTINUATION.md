# Capture Continuation

BZOGAK의 `이어 밑줄긋기`는 페이지를 넘겨 이어지는 문장을 하나의 글조각으로 저장한다. 일반적인 인용이 두 페이지를 넘기지 않는다는 전제에서 최초 촬영과 이어 촬영을 합쳐 최대 2페이지만 허용한다.

## 사용자 흐름

1. 첫 페이지에서 밑줄을 긋고 글조각을 저장한다.
2. 저장된 카메라 화면에 `새로 밑줄긋기`와 `이어서 밑줄긋기`를 함께 표시한다.
3. `이어서 밑줄긋기`를 누르면 카메라를 다시 열고 직전 글조각에 이어 붙이는 중임을 안내한다.
4. 두 번째 페이지에서 밑줄을 그으면 새 글조각을 만들지 않고 직전 글조각 본문 뒤에 덧붙인다.
5. 두 번째 저장 뒤에는 이어 촬영 버튼을 다시 표시하지 않는다.

이어 촬영을 취소하거나 인식에 실패해도 첫 페이지 글조각은 그대로 남는다. 취소한 뒤에는 새 글조각 촬영을 바로 시작할 수 있다.

캡처 화면에는 메모 입력 영역을 표시하지 않는다. 메모가 필요하면 저장한 글조각의 편집 화면에서 직접 추가한다.

촬영 버튼은 `글 캡처`, 촬영 후에는 `다시 캡처`와 `모든 글 저장`을 저장 완료 버튼과 동일한 캡슐형 스타일로 나란히 표시한다. 촬영 후 선택 화면에는 `밑줄이나 네모를 그려서 원하는 문장을 선택` 안내를 저장 버튼 위에 20pt 간격으로 표시한다.

촬영한 화면에서 밑줄이나 네모 선택이 끝난 뒤 0.8초 동안 추가 입력이 없으면 자동으로 OCR을 시작하고 선택한 글조각을 저장한다. 여러 번 그린 선택은 합쳐서 처리하고, 다시 그리기 시작하면 대기와 이전 인식을 취소한다. 버튼은 `선택 완료` 대신 비활성 `자동 저장` 상태를 표시하며 별도 탭이 필요하지 않다. 영역을 선택하지 않은 상태에서는 `모든 글 저장`을 유지한다. 기존 라이브 카메라 선택 동작은 변경하지 않는다.

## 사진 불러오기

- 초기 `글 캡처` 버튼은 중앙에, 사진 불러오기 버튼은 오른쪽 끝에 아이콘만 표시한다. 사진 아이콘은 카메라 아이콘과 같은 글꼴 크기·굵기를 사용하며 44pt 터치 영역과 접근성 이름 `사진 불러오기`를 유지한다. 기존 카메라 HUD의 중복 사진 버튼은 제거한다.
- 시스템 사진 선택창에서 한 장을 선택하면 촬영 직후와 동일한 정지 화면으로 진입한다. 불러오는 즉시 전체 본문을 저장하지 않는다.
- 밑줄·네모 선택 후 자동 OCR 저장, `모든 글 저장`, 지우개 동작은 촬영 이미지와 같은 경로를 사용한다.
- 카메라 권한이나 카메라 장치가 없어도 사진 불러오기를 사용할 수 있다.
- 사진 방향을 정규화하고 전체 사진이 보이도록 여백을 더해 기존 카메라 좌표계에 맞춘다. 원본 사진은 변경하지 않는다.
- 검증: iOS 시뮬레이터 빌드와 카메라 미지원 상태의 사진 선택창 열기를 확인했다. 실제 iPhone에서 사진 선택 후 영역 OCR·전체 저장, 가로 사진, iCloud 사진 로딩을 추가 확인한다.

## 선택 및 저장 처리

- 인식 대기·인식·저장 상태 라벨이 표시되는 동안 선택 안내 문구는 숨긴다.
- 버튼 줄 오른쪽의 지우개는 화면 선택 전체를 해제한다. 대기·인식·예약 저장을 취소하고 촬영 이미지는 유지한다. 이미 저장된 글조각은 삭제하지 않으며, 지울 선택이 없으면 숨긴다.
- 저장 완료와 이어 저장 완료 안내는 기존 위치보다 8pt 위에 표시한다.

- 한 장만 저장하면 기존처럼 선택 영역 양끝의 짧은 문장 파편을 정리한다.
- 첫 장을 저장할 때 화면에는 정리된 본문을 사용하되, 이어 촬영에 필요한 끝부분은 메모리에만 잠시 보관한다.
- 이어 촬영에서는 첫 장의 끝과 둘째 장의 시작을 보존하고, 전체 인용의 바깥쪽 파편만 기존 규칙으로 정리한다.
- 페이지 상단이나 하단의 독립된 페이지 번호는 본문에서 제외하되 첫 페이지의 페이지 정보에는 그대로 저장한다.
- 두 페이지 경계는 한글·영문과 문장부호를 고려한 OCR 줄 연결 규칙으로 합친다.
- 각 페이지 안의 문단 줄바꿈은 유지하고, 두 페이지가 맞닿는 지점에는 별도 줄바꿈을 넣지 않는다.
- 페이지 번호는 첫 페이지 값만 유지한다.
- 메모, 색상, 책 소속과 기존 태그는 유지한다.
- 두 번째 페이지를 붙인 뒤 합쳐진 전체 본문으로 자동 태그 생성을 다시 요청한다.
- 자동 태그가 늦게 도착해 본문이나 사용자의 편집을 덮어쓰지 않도록 기존 스냅샷 검증을 그대로 적용한다.
- 이어 붙이기는 저장소의 최신 글조각을 다시 조회한 뒤 본문만 갱신한다.
- 이어 촬영용 원문은 앱을 나가거나 새 촬영을 시작하면 즉시 버리며 영구 저장하지 않는다.

## 제한

자동 OCR 교정은 본문이 바뀌지 않았으면 최신 페이지·메모·태그·색상을 보존하고 본문만 적용한다. 교정을 적용할 수 없는 경우에도 최신 글조각으로 태그 생성을 진행한다. 태그 응답 대기 중 본문·메모·태그가 변경되면 기존 결과를 버리고 최신 상태로 한 번 재요청한다. 일시적인 통신 오류·429·5xx는 2초 후 한 번 재시도하며, 최종 실패는 현재 편집 중인 글조각에 한해 저장 성공과 태그 실패를 구분해 안내한다. 로컬 교정의 길이·모델 지원 제한은 그대로 유지한다.

한 글조각에는 한 번만 이어 붙일 수 있다. 더 긴 본문은 인용의 범위를 벗어나기 쉽고 OCR 오류 검토와 공유 가독성도 나빠지므로 별도 글조각으로 저장한다.
