# Capture Continuation

BZOGAK의 `이어 밑줄긋기`는 페이지를 넘겨 이어지는 문장을 하나의 글조각으로 저장한다. 일반적인 인용이 두 페이지를 넘기지 않는다는 전제에서 최초 촬영과 이어 촬영을 합쳐 최대 2페이지만 허용한다.

## 사용자 흐름

1. 첫 페이지에서 밑줄을 긋고 글조각을 저장한다.
2. 저장된 카메라 화면에 `새 글조각`과 `이어 밑줄긋기`를 함께 표시한다.
3. `이어 밑줄긋기`를 누르면 카메라를 다시 열고 직전 글조각에 이어 붙이는 중임을 안내한다.
4. 두 번째 페이지에서 밑줄을 그으면 새 글조각을 만들지 않고 직전 글조각 본문 뒤에 덧붙인다.
5. 두 번째 저장 뒤에는 이어 촬영 버튼을 다시 표시하지 않는다.

이어 촬영을 취소하거나 인식에 실패해도 첫 페이지 글조각은 그대로 남는다. 취소한 뒤에는 새 글조각 촬영을 바로 시작할 수 있다.

캡처 완료 뒤 메모로 자동 이동하거나 키보드를 열지 않는다. 한 장과 이어 촬영 모두 사용자가 메모 영역을 직접 눌렀을 때만 입력을 시작한다.

## 저장 규칙

- 한 장만 저장하면 기존처럼 선택 영역 양끝의 짧은 문장 파편을 정리한다.
- 첫 장을 저장할 때 화면에는 정리된 본문을 사용하되, 이어 촬영에 필요한 끝부분은 메모리에만 잠시 보관한다.
- 이어 촬영에서는 첫 장의 끝과 둘째 장의 시작을 보존하고, 전체 인용의 바깥쪽 파편만 기존 규칙으로 정리한다.
- 페이지 상단이나 하단의 독립된 페이지 번호는 본문에서 제외하되 첫 페이지의 페이지 정보에는 그대로 저장한다.
- 두 페이지 경계는 한글·영문과 문장부호를 고려한 OCR 줄 연결 규칙으로 합친다.
- 각 페이지 안의 문단 줄바꿈은 유지하고, 두 페이지가 맞닿는 지점에는 별도 줄바꿈을 넣지 않는다.
- 페이지 번호는 첫 페이지 값만 유지한다.
- 메모, 색상, 책 소속과 기존 태그는 유지한다.
- 두 번째 페이지를 붙인 뒤 합쳐진 전체 본문으로 자동 태그 생성을 다시 요청한다.
- 자동 태그가 늦게 도착해 본문이나 사용자의 편집을 덮어쓰지 않도록 기존 스냅샷 검증을 그대로 적용한다.
- 이어 붙이기는 저장소의 최신 글조각을 다시 조회한 뒤 본문만 갱신한다.
- 이어 촬영용 원문은 앱을 나가거나 새 촬영을 시작하면 즉시 버리며 영구 저장하지 않는다.

## 제한

한 글조각에는 한 번만 이어 붙일 수 있다. 더 긴 본문은 인용의 범위를 벗어나기 쉽고 OCR 오류 검토와 공유 가독성도 나빠지므로 별도 글조각으로 저장한다.
