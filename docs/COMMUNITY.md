# Community

## 개요

커뮤니티 탭은 책과 연결되는 외부 정보를 세 영역으로 제공한다.

- `내 주변`: 현재 위치에서 가까운 서점과 도서관
- `관련 글`: 책장에서 고르거나 직접 입력한 책과 관련된 NAVER·Daum 글
- `인기 도서`: 분야별 Aladin 베스트셀러와 도서관 대출 순위

지도는 표시하지 않는다. 장소 종류, 주소, 거리, 전화번호와 외부 상세 링크만 제공한다.

상단의 세 영역은 밑줄 탐색으로 구분하고, 각 영역 안의 출처·분야·검색 범위는 작은 필터로 표시한다. 주변 장소는 검색어가 이름에 들어갔는지가 아니라 Kakao가 제공한 실제 업종이 서점 또는 도서관인 결과만 노출한다.

## 구조

```text
iPhone app
  -> BZOGAK Vercel API
       -> Kakao Local / Kakao Book / Daum Blog
       -> NAVER Blog Search
       -> Aladin Open API
       -> 도서관 정보나루
```

앱은 제공자 API 키를 보관하거나 직접 전송하지 않는다. 모든 키는 Vercel 환경변수에만 둔다.

## API

| 경로 | 방식 | 기능 | 캐시 |
| --- | --- | --- | --- |
| `/api/v1/places` | `POST` | 주변 서점·도서관 | 없음 |
| `/api/v1/articles` | `POST` | 책 관련 글 | 없음 |
| `/api/v1/rankings` | `GET` | 분야별 판매·대출 순위 | 6시간 |
| `/api/v1/books/search` | `POST` | 책 정보 검색 | 없음 |
| `/api/v1/health` | `GET` | 배포 상태 확인 | 없음 |
| `/privacy` | `GET` | 개인정보 처리방침 | 1일 |

입력 길이, 페이지, 검색 반경을 서버에서 제한한다. 외부 제공자 오류의 원문이나 키는 사용자에게 노출하지 않는다.

- 관련 글은 `title`을 필수 검색어로 받고, 책장에서 고른 경우에만 `author`를 함께 사용한다.
- 판매 순위 분야는 Aladin의 `CategoryId`, 대출 순위 분야는 도서관 정보나루의 KDC 분류로 변환한다.
- 순위 종류가 바뀌면 해당 제공자가 지원하지 않는 분야 선택은 `전체 분야`로 돌아간다.

## 위치 정보

- 위치 권한은 사용자가 `내 주변`을 열었을 때만 요청한다.
- 앱은 한 번의 현재 위치 요청만 수행한다.
- 서버로 보낼 때 위도와 경도를 소수점 넷째 자리로 줄인다.
- 위치, 관련 글 검색어와 책 검색어는 URL에 넣지 않고 요청 본문으로 전송한다.
- 위치와 검색 응답은 CDN과 기기 네트워크 캐시에 보관하지 않는다.
- 위치를 앱 보관함이나 서버 데이터베이스에 저장하지 않는다.
- 권한을 거부해도 관련 글과 인기 도서는 그대로 사용할 수 있다.

## 배포

1. Vercel에서 새 프로젝트를 만들고 Root Directory를 `CommunityAPI`로 지정한다.
2. `CommunityAPI/.env.example`의 다섯 환경변수를 Production, Preview, Development에 등록한다.
3. 배포 후 `/api/v1/health` 응답을 확인한다.
4. Preview 또는 로컬 서버를 시험할 때만 `Config/Secrets.xcconfig`에서 `OVERLINE_API_BASE_URL`을 덮어쓴다.
5. 앱에서 책 검색, 관련 글, 순위, 위치 권한 허용·거부를 각각 확인한다.
6. 배포 주소의 `/privacy`가 로그인 없이 열리는지 확인한다.

Vercel Firewall에서 `/api/*`에 과도한 반복 요청을 제한한다. 정상 앱 사용과 캐시 재검증이 막히지 않도록 처음에는 완만한 기준으로 시작한다.

## 운영 원칙

- 외부 페이지는 원문 링크로 연다.
- 결과 출처를 행마다 표시한다.
- NAVER와 Daum의 반응 수는 검색 API가 제공하지 않으므로 추정하거나 표시하지 않는다.
- 일부 글 검색 제공자가 실패하면 가능한 제공자의 결과를 먼저 보여준다.
- 제공자 약관과 표시 요건이 바뀌면 배포 전 다시 확인한다.
- 기존 NAVER Developers 검색 API 키는 2027년 6월 30일까지 사용할 수 있다. 그 전에 NAVER API HUB로 이전한다.
