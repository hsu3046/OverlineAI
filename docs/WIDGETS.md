# 홈 화면 위젯

## 구성

- **다시 만난 글조각**: 소형 / 중형 / 대형. 최근 50개 글조각을 안정적으로 섞어 5분 슬롯마다 순환한다. 같은 후보 목록에서는 한 바퀴 동안 중복되지 않고 타임라인 재로드도 현재 슬롯의 문장을 바꾸지 않는다.
- 위젯 편집의 **책**을 지정하면 해당 책의 최근 글조각만 표시한다. 지정하지 않으면 전체 책을 대상으로 한다.
- 대형에는 최근 독서 기록 상태가 `reading`인 책 최대 2권과 책갈피 페이지를 표시한다.
- **인기 도서**: 중형 / 대형. 한국어·영어에서는 베스트셀러 또는 도서관 대출 순위를 선택한다. 일본어에서는 라쿠텐 판매순만 제공한다. 순위 캐시는 언어별로 분리해 24시간 유지한다.
- 글조각이나 책을 누르면 해당 책의 글조각 페이지로 이동한다. 편집창은 자동으로 열지 않는다. 순위 위젯은 커뮤니티의 해당 순위로 이동한다.

## 저장 구조

- 기존 SwiftData / UserDefaults 라이브러리는 이동하거나 변경하지 않는다.
- 앱과 확장의 App Group: `group.vote.aib.bzogak`.
- 앱: `vote.aib.bzogak.ios`, 위젯: `vote.aib.bzogak.ios.widgets`.
- `WidgetShared/WidgetData.swift`의 Codable DTO만 두 타깃에 포함한다. ONNX, 음성 모델, 앱 전체 데이터 모델은 확장에 포함하지 않는다.
- 앱은 실행 시와 기록 변경 시 `reading-v1.json`을 원자적으로 갱신한다. 동일 내용이면 재로드하지 않는다. 삭제, 초기화, 복원도 같은 경로를 거친다.
- 캡처한 글조각의 텍스트, 책 제목/저자, 페이지, 색상만 공유한다. 메모, API 키, 사진, AI 대화는 공유하지 않는다. 글조각 최대 500개, 각 800자, 관련 책 및 최근 읽는 책 최대 100권을 내보낸다.
- 파일은 첫 기기 잠금 해제 이후 접근 가능한 보호 수준을 사용하며 위젯의 개인 기록에는 `privacySensitive()`를 적용한다.
- 위젯 내보내기가 실패해도 원본 저장은 계속한다. 확장 읽기 실패 시 안내 화면을 표시한다.
- 순위는 확장만 별도 파일에 저장한다. 기존 `/api/v1/rankings` 공개 서버를 사용하며 제공자 API 키는 포함하지 않는다. 타임아웃 8초, 실패 시 지난 캐시 유지 후 1시간 뒤 갱신을 요청한다.

## iOS 동작과 제한

세로 점을 통한 수동 인용구 전환은 제거했다. 인용구는 5분 타임라인으로 자동 교체하며, 과거 페이지 위치 파일은 더 이상 읽거나 쓰지 않는다.

WidgetKit에 현재 엔트리와 향후 약 6시간의 5분 간격 엔트리 72개를 한 번에 제공한다. 저장된 글조각과 표지 캐시를 사용하며 5분마다 서버나 AI를 호출하지 않는다. 갱신과 실제 표시 시점은 배터리, 사용 빈도 등의 시스템 정책으로 달라질 수 있으며 정확한 5분 알람이 아니다.

홈 화면 색조/다크 모드에서는 시스템 배경과 전경 스타일을 따른다. 전체 색상 모드에서만 형광펜 색을 작은 포인트로 사용한다.

밝은 모드의 위젯 배경은 회색이나 크림색이 아닌 아주 옅은 청백색 `#FCFEFF`를 사용한다. 어두운 모드는 시스템 배경을 유지한다.

글조각 위젯은 상단 서비스 제목을 표시하지 않는다. 소형은 책 정보도 생략하고 본문만 13pt, 중·대형은 본문 15pt와 하단 책 정보를 표시한다. 모든 본문은 이탤릭이며 글자 크기는 Dynamic Type에 반응한다. 소형은 최대 8줄, 중형은 최대 5줄로 공간이 허용하는 만큼 표시한다. 중형 하단은 저자 없이 책 제목과 페이지를 한 줄에 배치한다.

저장된 형광펜 색을 본문에 22% 불투명도로 겹치고, 좌측 상단/우측 하단 모서리에 같은 색의 6pt 곡선 장식을 둔다. iOS 18 이상에서는 TextRenderer의 실제 줄 경계에 따라 색을 칠하고, 말줄임 시 마지막 글리프의 불투명도를 35%로 낮춘다. iOS 17에서는 16% 반투명 텍스트 배경과 기본 글줄임표를 사용한다.

렌더링 확인용 `Tests/Widgets/Render.swift`는 `WIDGET_RENDER` 컴파일 조건에서 크기를 주입한다. macOS ImageRenderer로 본문 레이아웃을 확인하는 도구이며 WidgetKit 홈 화면 호스트나 링크 동작을 대체하지 않는다.

모서리 장식의 직선 길이는 18pt에서 6pt로 줄이고 곡선과 굵기는 유지한다. 중형은 본문의 레이아웃 우선순위를 높이고 줄 간격/책 정보 간격을 줄여 다섯 줄을 우선 표시하며 책 정보는 하단 정렬한다. 화면 크기와 Dynamic Type에 따라 실제 줄 수는 달라진다.

대형의 출처 영역은 왼쪽에 38×54pt 표지, 오른쪽에 최대 두 줄의 책 제목과 저자/페이지를 둔다. 공유 책 정보에 선택적 표지 URL을 추가했으며 이전 스냅샷도 그대로 읽는다. 대형 타임라인에서 먼저 등장하는 서로 다른 책 최대 3권의 표지만 HTTPS로 최대 5초 동안 가져와 긴 변 160px로 축소한 JPEG를 App Group에 캐시한다. 본문 표시에는 표지가 필수가 아니며 누락/네트워크 실패 시 책 아이콘을 표시한다. 소·중형은 표지 네트워크 요청을 하지 않는다.

## 설치 및 확인

1. Xcode의 앱과 BZOGAKWidgets 타깃에서 동일한 개발팀을 사용한다. 두 타깃의 Signing & Capabilities에 App Groups가 있고 `group.vote.aib.bzogak`이 연결되었는지 확인한다. 실제 기기에서 새 그룹/확장 프로비저닝이 필요할 수 있다.
2. 앱을 설치하고 한 번 실행한 뒤 글조각을 저장한다.
3. iPhone 홈 화면 길게 누르기 → 편집 → 위젯 추가 → 글조각 서랍.
4. 세 크기, 긴 한국어 문장, 빈 보관함, 읽는 책 0/1/2권, 책갈피 유무, 다크/색조 모드를 확인한다.
5. 위젯 편집에서 특정 책 선택, 해당 책 삭제, 글조각 수정/삭제 후 반영을 확인한다. 삭제된 링크는 앱에서 안전하게 무시한다.
6. 글조각과 책 링크의 목적지를 확인한다. 네트워크를 끊어도 글조각은 그대로 표시되어야 한다. 순위는 캐시 또는 오류 안내를 표시한다.
