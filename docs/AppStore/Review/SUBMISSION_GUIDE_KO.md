# 심사 자료 사용 안내

## 준비된 파일

1. `APP_REVIEW_REPLY_EN.txt`: Apple의 여섯 질문에 대한 영문 답변. 심사 메시지 답변과 App Review Information > Notes에 같은 내용을 입력한다.
2. `docs/AppStore/Review/Attachments/BZOGAK-App-Review-Information.pdf`: 기능 사용 순서, 외부 서비스와 정보 흐름, 지역별 차이, 제3자 콘텐츠·라이선스, 심사용 OCR 예문을 담은 영문 첨부 자료.
3. 사용자가 촬영한 실제 iPhone 영상: 위 두 자료와 함께 첨부한다. 영상 촬영 완료는 사용자가 확인했으며, 영상 파일 자체는 아직 이 작업에 전달되지 않았다.

영문 답변에 기기 모델·iOS·빌드 번호를 추측해 넣지 않았다. 이 정보가 확보되면 1번 항목에 한 줄로 추가할 수 있다. 영상의 내용·최신 OS 여부·음성을 확인했다고 대신 진술하지도 않았다.

## 어디에 넣는지

1. App Store Connect의 해당 심사 메시지에서 답변을 연다.
2. 영문 TXT의 내용을 답변란에 입력하고 영상과 PDF를 첨부한다. TXT 자체를 첨부하는 것이 아니다.
3. App Review Information의 Notes에도 같은 영문 내용을 넣는다. Notes에서도 영상을 찾을 수 있도록 영상·PDF 첨부 위치를 확인한다. 별도 메시지에만 첨부했다면 해당 심사 메시지의 첨부를 참조한다고 Notes에 덧붙인다.
4. 최신 패치를 반영한 앱으로 재제출한다면 영상에 나온 동작과 같은 빌드를 선택한다. 기존 Build 3를 유지해야 하는 것은 아니다.

자료는 로컬에 준비했으며 App Store Connect에 입력하거나 재제출한 상태는 아니다. 2026-09-04에 최신 패치를 반영한 Version 1.0 / Build 4를 생성·업로드했다. Apple의 처리가 완료되어 선택 가능해지면 사용자가 Build 4를 선택하고 답변·첨부 자료와 함께 심사에 재제출한다.

## 답변 내용 요약

| Apple 요청 | 준비한 답변 |
| --- | --- |
| 1. 실제 기기 영상 | 촬영한 영상 첨부를 안내. 실제로 존재하지 않는 가입·결제 흐름은 없다고 설명 |
| 2. 목적·대상·가치 | 종이책의 문장·독서 기록을 보관하고 낭독하는 일반 이용자용 무료 앱 |
| 3. 주요 기능 접근 | 책 추가, 밑줄긋기, 낭독, 인사이트, 커뮤니티 순서와 외부 AI 설정 조건. PDF에 OCR 예문 포함 |
| 4. 외부 서비스 | Apple 프레임워크, 음성 모델·런타임·다운로드 호스트, Vercel, Kakao·NAVER·Aladin·정보나루, 외부 AI 제공자 |
| 5. 지역 차이 | 앱의 지역별 기능 스위치는 없지만 한국 중심 데이터와 기기·언어별 AI/음성 지원 차이는 있음 |
| 6. 제3자 콘텐츠 | 전문 규제 업종이 아님을 설명. 직접 제공하는 책 본문은 없으며 API 콘텐츠·라이선스 출처 공개 |

## 자료의 범위

- 기존 기능 테스트와 API 연동 성공 내역을 다시 미완료로 취급하지 않는다. 전면 재테스트나 키 재발급을 요구하는 안내가 아니다.
- PDF는 서비스·라이선스 설명 자료이지 외부 업체가 발급한 이용 승인서가 아니다. 별도로 보유한 등록·승인 증빙을 첨부한다면 비밀키는 가린다. 이번에 새 승인을 신청했다거나 모든 출판물의 권리를 보유한다고 진술하지 않는다.
- 외부 AI는 실제 제공자 API 키가 있어야 심사자가 실행할 수 있다. 파일에는 비밀키를 넣지 않았다. 기존에 심사용 접근을 제공했다면 그 정보를 연결하고, 제공하지 않았다면 허용된 접근 방법을 비공개 심사 정보로 따로 안내해야 한다. 영상만으로 직접 접근 요구가 면제된다고 보장하지 않는다.
- 외부 블로그는 읽기 전용이지만 이용자 작성 콘텐츠다. 신고·차단 기능이 현재 없다는 사실을 숨기거나 구현했다고 쓰지 않았다. 이번 2.1 요청과 별개로 Apple이 이 부분을 추가 확인할 가능성은 남아 있다.
- 운영 환경에 대한 새 테스트는 하지 않았다. 특히 도서관 정보나루는 구현된 연동으로 목록에 포함했으며, 미발급·미설정 상태라면 정상 제공 중이라고 제출하지 않는다. 기존 운영 확인 결과와 대조한다.

## 자료 갱신

PDF의 편집 원본은 `supporting_information.json`이며 `build_review_pdf.py`로 다시 만든다. 본문 TXT는 4,000자 제한을 고려해 작성했다. 기기 정보나 비공개 접근 안내를 추가한 뒤에도 제한을 확인한다.

[Apple 심사 메시지 답변·첨부 안내](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/)
