## App Store 표시 정보

### 부제

종이책 문장을 모으고 듣는 독서 기록

### 프로모션 문구

종이책에서 마음에 남은 문장을 카메라로 담고, 글조각과 독서 기록으로 모아 보세요. 촬영한 페이지를 기기 안의 자연스러운 음성으로 이어서 들을 수도 있습니다.

### 키워드

독서,책,문장,글귀,OCR,낭독,책장,독서기록,메모,서점,도서관

### 설명

글조각 서랍은 종이책을 읽으며 발견한 문장과 생각을 간직하고, 책 페이지를 음성으로 들을 수 있는 개인 독서 앱입니다.

카메라로 책 페이지를 비추고 마음에 남은 문장을 선택해 글조각으로 저장하세요. 페이지를 넘겨 이어지는 문장은 하나의 글조각으로 연결할 수 있습니다.

읽어주기에서는 여러 페이지를 연속으로 촬영한 뒤 자연스러운 음성으로 들을 수 있습니다. iPhone 음성과 선택형 고품질 온디바이스 음성을 지원하며, 화면을 잠그거나 다른 앱을 사용하는 동안에도 재생을 이어갈 수 있습니다.

책장에서는 책과 글조각을 한곳에 모으고, 독서 날짜와 별점, 감상문을 독서 기록으로 남길 수 있습니다. 선택한 글조각을 바탕으로 생각을 확장하는 인사이트 기능도 제공합니다.

커뮤니티에서는 가까운 서점과 도서관, 책과 관련된 글, 인기 도서를 찾아볼 수 있습니다.

개인정보를 소중히 다룹니다.

- 책, 글조각, 메모와 독서 기록은 기본적으로 이 iPhone에 저장됩니다.
- 촬영한 책 사진과 음성 메모의 녹음 파일은 처리 후 저장하지 않습니다.
- 외부 AI 기능은 기본으로 꺼져 있으며, 사용자가 직접 설정한 경우에만 작동합니다.
- 광고 식별자나 이용자 추적 SDK를 사용하지 않습니다.

## 제출 메모

- 연령 등급 설문에는 커뮤니티 탭에서 외부 블로그 검색 결과의 제목과 요약을 표시한다는 점을 반영해 `사용자 생성 콘텐츠`를 있음으로 답변한다. 앱 안에서 자유롭게 웹을 탐색하거나 글을 작성·공유·댓글·메시지를 보내는 기능은 없으므로 `무제한 웹 접근`, `소셜 미디어`, `메시지 및 채팅`은 없음으로 답변한다.
- 콘텐츠 권리 항목에는 Kakao, NAVER, Aladin과 도서관 정보나루의 검색 결과 및 메타데이터를 제공하고 원문은 외부 링크로 연다는 점을 설명한다.
- 심사팀 전달 내용은 `APP_REVIEW_NOTES.md`를 사용한다.
- 앱 아이콘 원본은 `Overline/BZOGAK.icon`, App Store용 확인 이미지는 `docs/AppStore/BZOGAK-AppIcon-1024.png`이며 Xcode의 App Icon 값도 `BZOGAK`으로 유지한다.

## 연령 등급 권장 답변

App Store Connect의 실제 문구와 선택지는 지역 및 시점에 따라 달라질 수 있다. 아래 내용과 의미가 같은 항목을 선택하고, 최종 등급은 App Store Connect가 계산한 결과를 사용한다.

| 항목 | 답변 | 근거 |

| 자녀 보호 기능 | 없음 | 보호자가 기능을 제한하는 별도 기능이 없음 |

| 사용자 생성 콘텐츠 | 있음 | NAVER와 Daum의 공개 블로그 검색 결과 제목과 요약을 표시함 |

## 스크린샷 구성

첫 제출은 6.9형 iPhone 규격의 실제 앱 화면 5장을 권장한다. 긴 저작물 본문이나 개인정보 대신 직접 작성한 예시 문장을 사용한다.

1. 밑줄긋기: 종이책 문장을 손가락으로 선택하는 화면
2. 읽어주기: 현재 문장을 강조하며 낭독하는 화면
3. 책장: 책과 최근 글조각을 모아 보는 화면
4. 독서 기록: 날짜, 별점과 감상문을 남긴 책 상세 화면
5. 인사이트 또는 커뮤니티: 모은 글을 바탕으로 생각을 정리하거나 책 정보를 찾는 화면

각 스크린샷은 앱이 실제로 동작하는 화면을 중심으로 구성하고, 카메라 화면에는 얼굴, 주소, 알림 등 개인 정보가 보이지 않도록 한다.
