# 종이책 페이지 읽어주기

## 범위

`캡처` 탭의 `읽어주기` 모드는 종이책 한 페이지를 촬영해 기기에서 OCR한 뒤 바로 낭독한다. 첫 페이지는 인식 직후 재생하며, 낭독 중 다음 페이지를 추가하면 순서대로 이어서 읽는다.

## 처리 흐름

1. 기존 `CameraTextScanner`로 현재 페이지의 정지 화면을 만든다.
2. Apple Vision의 정확도 우선 OCR로 한국어, 영어, 일본어 텍스트를 인식한다.
3. 문서 경계가 충분히 신뢰될 때 경계 안의 줄만 사용한다.
4. 페이지 상단 또는 하단의 페이지 번호와 페이지 번호가 붙은 책·챕터 표기를 제외한다.
5. 기존 OCR 문단 조립 규칙으로 본문을 정리한다.
6. 설정에서 선택한 로컬 음성으로 `AVSpeechSynthesizer`가 본문을 낭독한다.

낭독 큐는 최대 10쪽을 유지한다. 앞쪽 페이지를 이미 읽은 경우 오래된 페이지부터 메모리에서 제거해 다음 페이지를 받을 수 있다.

## 비저장 원칙

- 촬영 이미지, OCR 본문, 읽기 순서는 현재 화면의 메모리에만 둔다.
- 책장 데이터베이스, iCloud, 파일, `UserDefaults`에 저장하지 않는다.
- OCR과 낭독에 서버나 LLM을 호출하지 않는다.
- 화면을 닫으면 이미지와 OCR 본문을 즉시 비운다.
- 앱이 백그라운드로 이동하면 진행 중인 촬영과 OCR을 취소하고 낭독을 일시정지한다.
- 메모리 경고가 오면 전체 읽기 세션을 폐기한다.

음성 선택 설정만 기존 `QuoteSpeechPlayer`의 기기 설정을 재사용하며, 읽은 책 내용은 해당 설정에 포함되지 않는다.

## 현재 필터 범위

페이지 가장자리의 다음 형식을 본문에서 제외한다.

- 독립된 페이지 번호: `155`
- 페이지 표기: `p.155`, `155쪽`
- 페이지 번호와 같은 줄의 머리말·꼬리말: `책 제목 155`, `155 챕터 제목`

페이지 번호가 없는 반복 머리말·꼬리말은 한 장만으로 본문과 안전하게 구분하기 어렵기 때문에 자동 삭제하지 않는다. 여러 페이지에서 반복 여부를 확인하는 필터는 별도 품질 개선 대상으로 둔다.

## 실제 기기 검증

1. `캡처 > 읽어주기`에서 한 페이지를 촬영하고 자동 재생되는지 확인한다.
2. 상단, 하단, 중앙 페이지 번호와 책 제목이 붙은 페이지 번호가 낭독되지 않는지 확인한다.
3. 첫 페이지를 듣는 동안 다음 페이지를 추가하고 자동으로 이어 읽는지 확인한다.
4. 일시정지, 재생, 이전 페이지, 다음 페이지가 현재 위치와 맞는지 확인한다.
5. 화면 종료 확인 후 다시 열었을 때 이전 페이지가 남지 않는지 확인한다.
6. 낭독 중 앱을 백그라운드로 보내 재생이 멈추고 촬영 작업이 취소되는지 확인한다.
