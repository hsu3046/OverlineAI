# 글조각 서랍(BZOGAK) 개인정보처리방침

시행일: 2026년 9월 3일

최종 수정일: 2026년 9월 3일

에이아이비 주식회사(AIB Inc., 이하 "회사")는 iOS 앱 글조각 서랍(BZOGAK, 이하 "앱") 이용자의 개인정보를 중요하게 생각합니다. 이 방침은 앱에서 어떤 정보가 처리되는지, 정보가 언제 외부 서비스로 전송되는지, 이용자가 이를 어떻게 관리할 수 있는지 설명합니다.

본 방침은 글조각 서랍(BZOGAK) 앱에 적용됩니다. 회사의 다른 서비스에는 [AIB 개인정보처리방침](https://www.aib.vote/terms/privacy)이 적용됩니다.

## 1. 기본 원칙

- 앱의 책, 글조각과 독서 기록은 기본적으로 이용자의 iPhone에만 저장됩니다.
- 앱은 회원가입이나 로그인을 요구하지 않으며, 독서 기록을 회사 서버에 동기화하지 않습니다.
- 촬영한 책 사진과 음성 메모의 녹음 파일은 보관하지 않습니다.
- 위치와 검색어는 이용자가 해당 기능을 사용할 때만 전송됩니다.
- 외부 AI 기능은 기본으로 꺼져 있으며, 이용자가 명시적으로 동의한 경우에만 작동합니다.
- 앱은 광고 식별자를 사용하지 않으며, 다른 앱이나 웹사이트에서 이용자의 활동을 추적하지 않습니다.

## 2. 이 iPhone에 저장되는 정보

| 구분 | 저장되는 내용 | 보관 기간 |
| --- | --- | --- |
| 독서 보관함 | 책 정보, 글조각, 메모, 태그, 독서 기록, 감상문, 인사이트 | 이용자가 삭제하거나 앱을 삭제할 때까지 |
| 읽어주기 임시 보관 | OCR로 인식한 글과 마지막으로 읽던 위치 | 최대 3개, 각각 7일 후 자동 삭제 |
| 앱 설정 | 음성, 낭독 속도, 문장 간격, AI 제공자와 모델 선택, AI 전송 동의 여부 등 | 설정을 변경하거나 앱을 삭제할 때까지 |
| AI API 키 | 이용자가 직접 입력한 API 키 | 이용자가 설정에서 지울 때까지 |

독서 보관함은 iOS 앱 저장 공간에 보관됩니다. AI API 키는 iOS Keychain에 이 기기 전용으로 저장되며 회사 서버로 전송하거나 회사가 보관하지 않습니다. API 키를 완전히 지우려면 앱을 삭제하기 전에 설정에서 해당 입력값을 지워 주세요.

보관함 초기화 시 화면에 보이는 책, 글조각과 인사이트는 삭제되지만, 실수로 초기화한 경우를 대비해 직전 상태의 복구 백업이 이 기기에 남을 수 있습니다. 이 백업은 이후 초기화로 교체되거나 앱을 삭제하면 함께 삭제됩니다.

## 3. 사진, OCR와 음성의 처리

### 사진과 OCR

책 페이지를 카메라로 촬영하거나 사진 보관함에서 이미지를 선택하면, 앱은 해당 이미지를 기기 안에서 OCR 처리합니다. 촬영하거나 선택한 원본 이미지는 OCR 처리가 끝난 뒤 저장하지 않습니다. 사진 보관함에서는 이용자가 iOS 사진 선택 화면에서 직접 고른 이미지만 앱에 전달됩니다.

지원되는 기기에서는 Apple의 온디바이스 모델을 사용해 OCR 결과의 오탈자, 띄어쓰기와 줄바꿈을 자동으로 다듬을 수 있습니다. 이 과정에서 텍스트는 외부 서버로 전송되지 않습니다.

### 음성 메모

이용자가 음성 메모를 실행하면 마이크 입력을 Apple의 온디바이스 음성 인식으로 텍스트로 변환합니다. 녹음 파일은 저장하지 않으며, 변환된 텍스트는 이용자가 글조각의 메모로 저장한 경우에만 독서 보관함에 남습니다.

### 텍스트 낭독

iPhone 음성과 고품질 온디바이스 음성 모두 기기 안에서 텍스트를 음성으로 변환합니다. 낭독할 책 내용은 음성 합성을 위해 회사 서버나 음성 모델 제공자에게 전송되지 않습니다.

## 4. 사용하는 기기 권한

| 권한 | 사용하는 이유 |
| --- | --- |
| 카메라 | 책 페이지의 글과 ISBN 바코드를 인식하기 위해 사용합니다. |
| 마이크 | 이용자가 음성으로 메모를 남길 때만 사용합니다. |
| 음성 인식 | 음성 메모를 기기 안에서 텍스트로 변환하기 위해 사용합니다. |
| 위치 | 이용자가 `내 주변` 기능을 열었을 때 가까운 서점과 도서관을 찾기 위해 사용합니다. |

권한은 필요한 기능을 처음 사용할 때 iOS가 요청합니다. 이용자는 언제든 iPhone의 `설정 > 개인정보 보호 및 보안`에서 권한을 변경할 수 있습니다. 권한을 허용하지 않아도 해당 권한이 필요하지 않은 다른 기능은 계속 사용할 수 있습니다.

## 5. 외부로 전송되는 정보

### 주변 장소

이용자가 `내 주변` 기능을 사용할 때 현재 위치, 검색 반경과 장소 종류가 암호화된 연결을 통해 BZOGAK 커뮤니티 API와 Kakao에 전송됩니다. 이 정보는 가까운 서점과 도서관을 찾는 데만 사용됩니다.

앱은 위치 좌표를 전송하기 전에 소수점 넷째 자리로 반올림합니다. BZOGAK 커뮤니티 API는 위치 요청 본문과 검색 결과를 별도의 데이터베이스에 저장하거나 캐시하지 않습니다. 다만 서버 운영 및 보안을 위한 접속 기록은 호스팅 업체의 정책에 따라 제한적으로 처리될 수 있습니다.

### 관련 글과 도서 검색

관련 글이나 책을 검색할 때 이용자가 입력한 검색어, 책 제목 또는 저자 정보가 BZOGAK 커뮤니티 API와 검색 결과를 제공하는 Kakao, NAVER 또는 Aladin에 전송될 수 있습니다. 인기 도서 기능을 사용할 때는 선택한 분야와 목록 종류가 Aladin 또는 도서관 정보나루에 전달될 수 있습니다.

BZOGAK 커뮤니티 API는 이러한 요청 본문과 검색 결과를 별도의 데이터베이스에 저장하거나 캐시하지 않습니다. 이용자가 검색 결과의 외부 링크를 열면 해당 웹사이트의 개인정보처리방침이 적용됩니다.

### 선택적 외부 AI 기능

외부 AI 기능은 기본으로 꺼져 있습니다. 이용자가 설정에서 `AI로 글 보내기`를 직접 켠 경우에만 다음 정보가 현재 선택한 OpenAI, Anthropic, Google 또는 OpenRouter로 전송될 수 있습니다.

- 이용자가 AI 기능에 사용하기로 선택한 글조각과 메모
- 책 제목, 저자 등 관련 책 정보
- 인사이트, 태그, OCR 교정 또는 감상문 초안 생성을 위한 요청 내용

앱은 현재 선택된 제공자 한 곳에만 요청을 보냅니다. 이용자는 언제든 설정에서 동의를 끌 수 있으며, 제공자를 변경하면 새 제공자에 대해 다시 동의해야 합니다. 회사는 외부 AI 제공자에게 응답의 영구 저장을 요청하지 않지만, 각 제공자는 보안과 서비스 운영을 위해 전송된 정보를 자체 정책에 따라 처리할 수 있습니다.

### 고품질 음성 팩 다운로드

이용자가 고품질 온디바이스 음성 팩을 다운로드하면 모델 파일을 받기 위해 Hugging Face와 통신합니다. 이때 IP 주소 등 일반적인 접속 정보가 해당 서비스에 전달될 수 있지만, 이용자의 책, 글조각, 메모 또는 낭독할 텍스트는 전송되지 않습니다.

### 공유

이용자가 앱의 공유 버튼을 누르면 iOS 공유 화면을 통해 선택한 앱이나 사람에게 책 정보, 글조각 또는 독서 기록을 직접 보낼 수 있습니다. 공유는 이용자의 선택으로 이루어지며, 공유 이후에는 이용자가 선택한 서비스의 개인정보처리방침이 적용됩니다.

## 7. 보관 기간과 삭제

- 촬영하거나 선택한 책 사진: OCR 처리 후 저장하지 않습니다.
- 음성 메모 녹음 파일: 텍스트 변환 후 저장하지 않습니다.
- 위치와 검색 요청: BZOGAK 커뮤니티 API의 데이터베이스에 저장하거나 응답을 캐시하지 않습니다.
- 읽어주기 임시 보관: 항목별로 7일 후 자동 삭제되며, 3개를 넘으면 가장 오래된 항목부터 삭제됩니다.
- 책, 글조각, 메모, 독서 기록과 인사이트: 이용자가 앱에서 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다.
- AI API 키: 이용자가 설정에서 지울 때까지 iOS Keychain에 보관됩니다.
- 고품질 음성 팩: 이용자가 설정에서 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다.

앱을 삭제하면 앱의 저장 공간에 있는 독서 데이터, 설정, 임시 보관 글과 음성 팩이 삭제됩니다. iOS Keychain의 특성상 API 키는 앱을 삭제한 뒤에도 기기에 남을 수 있으므로, 삭제를 원하면 앱 설정에서 API 키를 먼저 지워 주세요.

## 8. 이용자의 선택과 권리

이용자는 앱과 iPhone 설정에서 다음 항목을 직접 관리할 수 있습니다.

- 책, 글조각, 메모, 독서 기록과 인사이트의 개별 삭제
- 보관함 초기화와 최근 초기화 복구
- 읽어주기 임시 보관 항목의 삭제
- 고품질 음성 팩의 삭제
- AI API 키의 변경 또는 삭제
- `AI로 글 보내기` 동의 철회
- 카메라, 마이크, 음성 인식과 위치 권한 변경

회사가 보유한 접속 기록 등 개인정보에 대한 열람, 정정, 삭제 또는 처리 정지를 요청하려면 아래 연락처로 문의할 수 있습니다. 앱의 독서 데이터는 회사 서버에 저장되지 않으므로 회사가 대신 조회하거나 복구할 수 없습니다.

## 9. 정보 보호

- 모든 외부 통신에 HTTPS를 사용합니다.
- AI API 키는 iOS Keychain에 이 기기 전용으로 저장합니다.
- 고품질 음성 모델 파일에는 iOS 파일 보호 기능을 적용합니다.
- 위치와 검색 요청에는 서버 및 네트워크 캐시를 사용하지 않습니다.
- API 키, 글조각 전문과 메모 내용을 앱의 진단 로그에 기록하지 않습니다.
- 광고 SDK와 이용자 추적 SDK를 사용하지 않습니다.
