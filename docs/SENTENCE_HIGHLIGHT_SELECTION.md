# 줄 긋기: 문장 단위 선택

## TL;DR

2026-09-15 사용자 승인 B안: 한 번 그은 위치에서 문장 하나를 선택하고, 같은 source range로 하이라이트와 저장 내용을 만든다. 사각형/전체 인식은 기존 영역/페이지 경로를 유지한다.

## 원인

기존 `.line` 경로는 최고 점수의 74% 이상인 후보를 최대 8개 선택했다. 글줄 전체를 선택한 다음, 그 범위에 32% 이상 걸친 문장을 다시 확장하므로 인접 글줄과 같은 줄의 다른 문장이 함께 저장될 수 있었다.

## 변경

1. 원래 손가락 경로를 사용한다. 선 끝을 8pt씩 늘리던 보정 결과는 문장 선택에 사용하지 않는다.
2. 방향과 겹침을 검사하고 경로를 재샘플링해 기준 글줄 하나를 결정한다. 글자 영역을 직접 통과하는 선을 우선한다. 글자 아래의 줄 간격은 위쪽 글줄의 밑줄 영역에, 세로글 오른쪽의 열 간격은 왼쪽 열의 표시 영역에 배정한다. 여백 허용 범위는 이웃 글자 영역을 넘지 않는다. 두 후보 점수 차이가 2pt 미만이면 보류한다.
3. Vision 글자 범위별 좌표를 보존한다. `NLTokenizer(.sentence)`가 분리한 문장 중 손가락 경로와 가장 많이 겹치는 문장 하나를 선택한다. 2위 겹침이 1위의 85% 이상이면 보류한다.
4. 선택한 문장이 다음 줄/열로 이어질 경우 그 문장의 source slice만 포함한다. 문자열 검색으로 다른 위치를 교체하지 않는다. offset은 원본 Swift Character 기준이다.
5. 문장 조각은 원본 글줄 ID와 범위를 가진 별도 스냅샷으로 캐시한다. 같은 문장 재선택은 같은 ID로 합쳐지고, 동일한 문구가 다른 글줄에 있으면 별도로 유지한다.
6. 정확한 선택은 기존 32% 문장 확장/앞뒤 조각 제거를 통과하지 않는다. 표시와 저장에 동일한 스냅샷을 쓰며 하이라이트 양 끝 장식 확장을 끈다.
7. 부분 문장에 필요한 글자 좌표가 없으면 가로 폭 비율로 추정하지 않는다. 여러 제스처 중 일부가 모호하면 확정된 부분만 저장하지 않는다.

영역과 줄 긋기를 함께 사용한 경우, 전체 글줄을 포함한 영역 선택이 그 글줄의 부분 스냅샷보다 우선하여 중복 저장을 막는다.

## 구현 위치

- `Overline/OCRSentenceSelector.swift`: 방향/거리 판정, 문장 토큰화, source slice 및 부분 영역 생성.
- `Overline/OCRDocumentRecognizer.swift`: 글자별 OCR 좌표 보존. 구형 Vision 경로에서도 같은 좌표 추출 헬퍼 사용.
- `Overline/CameraTextScanner.swift`: 정확한 문장 스냅샷 캐시, 표시/저장 공용 경로.
- `Overline/CaptureView.swift`: 줄 긋기 연결, 모호한 선택 안내, 하이라이트 범위 제한.

## 검증

`bash Tests/OCRDocumentRecognition/run.sh`

- 가로 한 줄의 첫 문장/두 번째 문장을 따로 선택.
- 인접 가로줄/세로열 제외, 중간선의 모호한 선택 보류.
- 아래→위 세로 긋기, 다음 열로 이어진 한 문장 선택.
- 일본어 닫는 따옴표 보존, 소수점 문장 경계 처리.
- 글자 좌표 누락 및 두 문장을 비슷하게 그은 경우 보류.
- 선택 source range와 저장 문자열/하이라이트 영역 일치.
- 합성 이미지 → 실제 Vision 글자 좌표 → 한국어/일본어 두 번째 문장만 선택하는 통합 테스트.
- 기존 가로·세로 OCR, 문장 조립, 제스처 방향 회귀 테스트.

실기기 터치 재확인은 필요하다: 한 줄의 문장 하나만 긋기, 가까운 줄 간격, 세로 한 문장, 여러 줄에 걸친 문장, 여러 번 긋기, 사각형 및 전체 저장.

## 후속: 밑줄 위치의 선택 거부

사용자는 ‘문장을 하나로 정하기 어려워요’ 안내와 함께 줄 긋기 실패를 보고했다. 글자 중앙선의 평균 거리와 중간선 제한으로 실제 밑줄 위치가 동점/거부되는 경우를 합성 좌표로 재현했다. 글자 위의 긋기와 여백의 밑줄을 구분하는 방식으로 수정했다. 실제 실패 터치 좌표는 수집하지 않았으므로 실기기 원인 일치·해소 여부는 재확인 대상이다.

회귀 테스트에 글자 하단, 줄 간격의 여러 위치(다음 글줄 직전 포함), 다음 글줄 위 직접 긋기, 일본어 세로열 여백 긋기를 추가했다. 기존 OCR·문장·스냅샷 테스트도 유지한다.
