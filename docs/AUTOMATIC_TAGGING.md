# Automatic Tagging

Overline은 캡처 저장 후 글조각을 다시 찾기 쉽도록 태그를 자동 보강한다. 목표는 저장 속도를 늦추지 않으면서, 사용자가 반복해서 쓰는 주제어를 자연스럽게 재사용하고, 설정된 AI가 있으면 짧은 태그를 추가 제안하는 것이다.

## 동작 원칙

1. 글조각 저장은 먼저 완료한다.
2. 책에 등록된 기본 태그를 즉시 붙인다.
3. 같은 책에서 반복적으로 나온 태그를 다음 캡처의 기본 후보로 재사용한다.
4. AI 설정이 준비되어 있으면 저장 후 백그라운드에서 태그를 보강한다.

자동 태그는 캡처 UX를 막지 않는다. AI 호출이 실패해도 저장된 글조각은 그대로 유지된다.

## 발동 시점

아래 저장 경로에서 글조각이 저장된 직후 `scheduleAutomaticTagGeneration`이 실행된다.

- 카메라/OCR 캡처 저장
- 갤러리 사진 OCR 저장
- 메모만 저장하는 quick thought 저장

사용자가 메모를 나중에 수정하면 기존 저장 로직이 글조각을 amend한다. 자동 태그 보강은 저장 직후 한 번만 시도한다.

## 로컬 태그 재사용

로컬 재사용은 외부 AI를 쓰지 않는다.

- 책 편집 화면에 등록한 태그는 해당 책의 모든 새 글조각 기본 태그가 된다.
- 같은 책 안에서 2회 이상 반복된 태그만 다음 캡처 후보에 추가한다.
- 반복 태그는 많이 나온 순, 최근에 나온 순으로 정렬한다.
- 책 기본 태그와 반복 태그를 합쳐 중복을 제거한다.

한 번만 나온 태그는 기본 후보로 올리지 않는다. 오작동이나 임시 태그가 다음 캡처에 번지는 것을 막기 위함이다.

## AI 태그 보강

AI 태그 보강은 설정된 provider가 있을 때만 실행한다. 우선순위는 아래와 같다.

| 우선순위 | Provider | 모델 |
| --- | --- | --- |
| 1 | Anthropic | `claude-haiku-4-5-20251001` |
| 2 | OpenAI | `gpt-5.4-mini` |
| 3 | Gemini | `gemini-3.1-flash-lite` |

OpenRouter는 자동 태그 보강용 경량 모델 경로에서 제외한다.

AI에는 아래 정보만 보낸다.

- 책 제목
- 저자
- 책 소개
- 선택된 글조각 텍스트
- 글조각 메모
- 이미 붙은 태그

페이지 번호, 저장 날짜, 생성 시각은 태그 생성 근거로 보내지 않는다.

## 프롬프트 규칙

AI에는 `태그` 전용 모드로 요청한다.

- JSON만 반환
- 형식: `{"tags":["태그1","태그2"]}`
- 2-4개 태그
- `#` 기호 금지
- 설명 문장, 마크다운, 머리말 금지
- 짧은 한국어 명사형 우선
- 너무 일반적인 태그 금지: 책, 글, 글조각, 문장, 인용, 메모, 독서, 한국어 등
- 책 정보는 배경으로만 쓰고, 선택된 글조각의 핵심 주제를 우선

앱은 응답을 다시 정규화한다. `#`가 붙어 있으면 제거 후 다시 붙이고, 내부 공백은 제거한다.

## 저장 규칙

- 기존 태그는 유지한다.
- AI가 만든 태그는 기존 태그 뒤에 추가한다.
- 중복 태그는 제거한다.
- 글조각 하나의 태그는 최대 6개까지만 보강한다.
- 사용자가 직접 편집한 기존 태그를 자동 태그가 삭제하거나 덮어쓰지 않는다.

## 로그

자동 태그는 `CaptureMetrics` 로그에 provider, model, 결과 개수, 실패 타입만 남긴다.

- `auto_tags_requested`
- `auto_tags_empty`
- `auto_tags_applied`
- `auto_tags_failed`

API 키, access token, 글조각 전문은 로그에 남기지 않는다.

## 개인정보 원칙

자동 태그 보강은 사용자가 AI provider를 설정한 경우에만 외부 AI로 요청한다. 설정이 없으면 로컬 태그 재사용만 동작한다.

배포 전에는 설정 화면과 개인정보 문구에서 아래를 명확히 해야 한다.

- 글조각 저장 후 태그 추천을 위해 선택한 글조각과 책 정보가 설정된 AI provider로 전송될 수 있다.
- AI provider가 설정되지 않은 경우 외부 전송 없이 로컬 태그만 재사용된다.
- 사용자는 AI 연결을 해제해 자동 태그 보강을 멈출 수 있어야 한다.
